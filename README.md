# Coffee Shop Sales Analysis

A comprehensive sales analysis project for coffee shop operations, featuring detailed data visualizations and insights into sales trends, customer behavior, and operational metrics.

## 📊 Project Overview

This project analyzes coffee shop sales data to identify key business metrics, trends, and insights. It includes raw transactional data, processed analysis, and visual reports to help understand customer purchasing patterns and sales performance.

## 📁 Files

- **Coffee_Shop_Sales.xlsx** - Processed and cleaned sales dataset with analysis-ready data
- **Row Data of Coffee Shop Sales.xlsx** - Raw transactional data from coffee shop operations
- **Coffee Shop Sales Analysis_pdf.pdf** - Comprehensive analysis report with visualizations and insights
- **Screenshot 2026-09-06 011144.png** - Visual preview of key metrics and dashboards

## 🔍 Key Insights

The analysis covers:
- Sales trends over time
- Product performance and popularity
- Customer demographics and behavior
- Peak sales periods and seasonal patterns
- Revenue distribution and profitability
- Operational metrics and KPIs

## 📈 Visualizations

The project includes multiple charts and dashboards showing:
- Time-series sales trends
- Product category analysis
- Customer segmentation
- Daily and hourly sales patterns
- Top-performing items and locations

## 🚀 Getting Started

1. **Explore the Data**: Open `Coffee_Shop_Sales.xlsx` in Excel or any spreadsheet application
2. **View Raw Data**: Review `Row Data of Coffee Shop Sales.xlsx` for transaction-level details
3. **Read the Analysis**: Check `Coffee Shop Sales Analysis_pdf.pdf` for detailed insights and recommendations
4. **Visual Overview**: See `Screenshot 2026-09-06 011144.png` for a quick dashboard preview

## 📋 Data Structure

The dataset includes columns for:
- Transaction ID and date/time
- Product information (name, category, price)
- Quantity sold
- Revenue generated
- Customer and location details
- Payment method

## 💡 Use Cases

- Identify best-selling products and categories
- Optimize inventory management
- Improve staffing schedules based on peak hours
- Develop targeted marketing strategies
- Forecast future sales and revenue
